## Price per litre formula

```
Price per litre (₹) = Listed price (₹) ÷ Pack size in litres
Example: ₹833 for 2L = ₹833 ÷ 2 = ₹416.50/L
```

## Process claim vocabulary

| Term | Meaning |
|------|---------|
| Cold-pressed | Pressed without heat; temperature controlled |
| Wood-pressed | Pressed using wooden ghani / chekku |
| Kachi ghani | Hindi — cold / raw press |
| Chekku | Tamil/Telugu — wooden press |
| Ganuga | Telugu — wooden press |
| Steel-pressed | Rotary chekku using steel components — may generate some heat |
| Expeller-pressed | Mechanical screw press — typically generates heat |
| Refined | Solvent/heat processed — not premium |
